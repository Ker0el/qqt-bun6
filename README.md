# QQ堂 · 抢包山 6 网页复刻

当前版本 0.6.0，本地入口：http://localhost:8787。

## 启动

双击 `启动游戏.cmd`。结束服务使用 `停止游戏.cmd`。本机依赖已安装；其他电脑需 Node.js 22+。

也可以在此目录运行 `npm ci --omit=dev --ignore-scripts`，再运行 `npm start`。

## 操作与联机

- 方向键 / WASD 移动，空格放泡。顶住墙时仍播放跑步动画。
- 回车打开聊天，再按回车发送，Esc 收起。未进房时发到大厅，进房后仅发到当前房间。
- 大厅实时展示公开房间和人数，可直接加入；2–8 名真人，双方人数相等且其他玩家准备后，由房主开局。
- 单人训练不出现在大厅，不含人机。
- 同一局域网使用房主电脑的局域网地址访问 8787 端口；游戏“玩法说明”里可以看到地址。
- 声音默认关闭，可在下方工具栏开启；自己的放泡声音仅自己听到。
- “赞赏”按钮显示用户提供的赞赏码，不会自动付款。

## 抢包规则

每队固定三个包子。把对方三个包子带回自己房内即可获胜，不要求自己的包子全都在家。单人正常训练抢齐也会结算。

房屋四角有碰撞并挡火，中间十字通道可以进入，也能被炸到。进房后模型隐藏，自己的位置箭头保留。背包时减速且不能放泡；掉包后须拾取并背回，不能碰一下就瞬间归位。

糖泡当前按客户端逆向记录采用约 3 秒引爆。爆炸按瞬间覆盖判伤，恰好半身不命中；现存地面道具可以被炸毁，新从墙内显露的道具不会被同一次爆炸抹掉。砖块消失后有 0.2 秒碎裂碰撞过渡，残留火焰动画不重复判伤。

被困后可由队友营救，敌人接触会击破；死亡后显示透明复活倒计时，可以继续看场上状况。

## 穿技与图层

单人练习提供贴泡穿、走穿、上墙、上柱、转向上墙和房屋场景。按 R 重置。

面向目标的短按、持续接近、助跑都能建立穿泡节奏，约 0.6 秒时放泡；目前容错窗口为 0.42–0.82 秒，是按用户手感反馈放宽的设置，不是声称已逐帧复现原版判定。穿势持续时间随速度变化。

静态障碍边缘可以自动滑动，对泡弹不做自动横向吸附。穿入墙格后进入独立前景绘制层，留在墙内时保持置顶，回到地面则恢复正常遮挡。其他玩家名字在头顶，自己只显示箭头；背包图标在场景前方绘制。

## 单人训练 F2 MOD

- 无限泡弹：解除角色泡数上限，仍遵守每格一泡。
- 无限速度：60 格/秒的训练速度。
- 无限威力：覆盖整张地图的威力。
- 无敌、穿墙。
- 显示墙内道具：展示开局已生成的真实隐藏道具；开启穿墙后走进对应墙格可拾取，炸墙不会再重复生成该道具。
- 秒赢：演示三次往返拿包、交包，然后结算。

上述修改由服务端限制为单人训练。公开联机房间会拒绝训练指令，隐藏道具位置也不会随普通对局快照发送。
